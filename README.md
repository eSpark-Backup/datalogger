# DataLogger
There will be two versions of the datalogger, a basic version and an advanced version.

# Basic Version
The purpose of the basic version of the datalogger is to log and save temperature and humidity readings automatically at predefined intervals. The user will have an option to log the temperature and humidity data instantly when a push button is pressed.

- Ultra low power MCU should be selected.
- The device will incorporate a ultra low power display to show the readings.
- The device will save the readings and users can easily retrieve it through a USB or card connection or suitable low power approach.
- A push button to instantly log the readings irrespective of the interval.
- Select and use an appropriate sensor with accuracy of about ±0.5°C
- The device will be powered by a CR2032 or CR2477 coin cell

# Advanced Version
The purpose of the basic version of the datalogger is to log and save temperature and humidity readings automatically on the device as well as readings will be sent to cloud through WiFi. The intervals of the data can be configured through the cloud interface.

- Ultra low power MCU with WiFi should be selected.
- The device will incorporate a ultra low power display to show the readings.
- A push button to instantly log the readings irrespective of the interval.
- Select and use an appropriate sensor with accuracy of about ±0.2°C with configurable alert thresholds.
- Suggest suitable battery approach with maximum battery life.
